# Starcross: The star chart
Audience: Luna, playing Starcross
Keywords: Starcross, star chart, mass detector, coordinates, range, theta, phi, course, navigation, computer, Bridge, UM, asteroid
Summary: The mass detector printout that came in the Starcross box, which every player needs: coordinates (range, theta, phi) for the uncharted masses, asteroids, an inhabited asteroid and a ship, and how to give them to the ship's computer.

## How to set a course
1. On the Bridge, EXAMINE DETECTOR (or read its screen). It shows the name of the mass it found, like "mass UM52". It isn't always the same one.
2. Find that name in the table below.
3. Tell the computer all three numbers: COMPUTER, RANGE IS 175. THETA IS 165. PHI IS 35
4. It won't start a new course until you confirm: COMPUTER, CONFIRM NEW COURSE
5. The computer warns you about the burn that follows. Listen to it: a burn means real G forces.

## Bridge
The mass detector is here: EXAMINE DETECTOR shows which mass it found. Its coordinates (range, theta, phi): UM08 150 110 17, UM12 100 345 107, UM24 100 285 87, UM28 250 45 178, UM31 150 105 67, UM52 175 165 35, UM70 100 135 101, UM91 50 15 121. Set a course with COMPUTER, RANGE IS (R). THETA IS (T). PHI IS (P) then COMPUTER, CONFIRM NEW COURSE. The computer warns you before a burn: take it seriously.
